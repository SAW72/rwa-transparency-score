## 1. Scope
This Privacy Policy explains how we handle information when you use RAT, including the Streamlit demo and any optional X (Twitter) features that let you authorize posting of score cards.

## 2. Information we may collect
**A. Information you provide**
- Optional account or contact details if you email us
- If you connect X: tokens/identifiers X provides after you authorize our app (we do **not** receive or store your X password)

**B. Information generated by the Service**
- Tickers/symbols you search or compare
- Scores, bands, explanations, and related demo outputs
- Whether you use **fixture/demo mode** or live third-party data mode

**C. Technical / log data**
- Standard server and hosting logs (e.g. IP address, user-agent, timestamps, request paths) from Render or similar hosts
- Basic analytics if enabled later (we will update this policy if we add analytics cookies beyond essential hosting)

**D. Third-party data displayed in scores**
- CoinMarketCap (or similar) RWA/market fields when live mode is on
- Bundled **demo fixtures** when fixture mode is on (not live API data)

We do **not** ask for seed phrases, private keys, government IDs, or payment card numbers for the demo.

## 3. How we use information
- Operate and improve the demo
- Generate and display transparency scores
- If you opt in: post or prepare score-card content to X on your behalf under the permissions you grant
- Secure the Service, prevent abuse, and debug errors
- Comply with law

We do **not** sell personal information.

## 4. X (Twitter) optional feature
If you authorize our X app:
- We use OAuth credentials only to perform the actions you request (e.g. posting a score card) and to maintain the connection while enabled
- You can revoke access anytime in your X account settings
- We do not store your X password
- X’s own privacy policy also applies to data X processes

## 5. Sharing
We may share information with:
- **Hosting / infrastructure** providers (e.g. Render)
- **Model/data providers** when live mode calls third-party APIs (e.g. CoinMarketCap)
- **X**, when you authorize posting
- Authorities when required by law

Public posts you authorize on X are public by nature.

## 6. Retention
- Server logs: typically a short rolling window (target ≤ 90 days unless needed longer for security or legal reasons)
- OAuth tokens: retained only while the connection is active or as needed to complete a requested post; delete/revoke when you disconnect
- On-disk demo state is ephemeral unless we later add accounts (we will update this policy if we do)

## 7. Security
We use reasonable technical measures. No method is 100% secure. This is an experimental hackathon/demo Service.
